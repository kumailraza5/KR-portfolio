Zeina Atelier: Shopify theme customization for a wedding stationery storefront

Project overview

Context and scope

Zeina Atelier is presented in my portfolio as a wedding stationery storefront where product presentation and thoughtful layout were central to the theme work. The project focused on how customers encounter collections, view stationery details and move through the store.

The portfolio describes custom Shopify OS 2.0 theme work rather than a complete new commerce platform. The documented areas include homepage and collection layouts, product colour options, navigation, reusable sections and responsive storefront troubleshooting.

Problem and approach

What the storefront needed

Wedding stationery combines visual storytelling with specific purchase decisions: customers browse a collection, compare options and need clear routes to product details. The project brief reflected in the portfolio called for a more considered editorial experience while keeping the store useful on smaller screens.

Because this is theme-focused work, a practical constraint is keeping changes integrated with Shopify templates and sections instead of treating the storefront as a standalone React application.

Documented work

Features and implementation areas

Editorial page and collection layouts

The project records custom homepage, Edits and collection layouts. These are the areas where the theme can establish visual hierarchy and help customers move from a brand introduction to stationery categories.

Product colour options and navigation

The portfolio includes product colour options and navigation work. Clear product choices and understandable site structure are important usability concerns in a stationery storefront.

Reusable Shopify sections

Shopify OS 2.0 and Liquid are part of the documented implementation. Section-based theme work supports content changes without rebuilding every page by hand.

Responsive storefront and cart troubleshooting

Responsive behaviour and cart-related troubleshooting were included in the project scope. This case study does not claim measured cart or conversion improvements.

Engineering considerations

What went into the build

Work within the theme

Shopify Liquid templates, sections, JavaScript and CSS provide the implementation layer for custom storefront behaviour.

Keep layouts coherent

Homepage, product and collection experiences need consistent content hierarchy even when individual templates serve different purposes.

Check real shopper paths

Navigation, option selection, cart actions and mobile presentation are practical areas to review after theme edits.

Evidence, not invented metrics

What this project demonstrates

The project is evidence of hands-on Shopify theme customization across several real storefront touchpoints. Publicly verified speed scores, conversion rates or revenue uplift are not available, so no numerical outcome is claimed.
